Scripts used for analyses are provided here in R format (.R extension).
Data to reproduce these results is available on figshare (ADD LINK).

This folder or directory has 4 scripts. 1, 2, and 4 should be run sequentially. 3 should NOT be run (see below).

1. 01_get_acoustic_measuresXX.R

	- INPUTS: spectro_analysis_2025-11-16.RDS, fundfreq_measures_2025-05-08.RDS, not_batcalls, trial_times.csv
	- Combines results from warbleR::spectro_analysis and fundamental frequency contour summary measures into one data frame.
	- Removes sounds that are not contact calls.
	- Makes table of calls per pair per session per bat.
	- Makes heatmap of the number of calls between bat pairs.
	- PRODUCTS: vocal_data_2024-pairs_XXXX-XX-XX.RDS, calls_per_session.csv
	
2. 02_model_number_of_calls_XX.R

	- INPUTS: vocal_data_2024-pairs_XXXX-XX-XX.RDS, OSU_2024_social_data.csv, KING.txt
	- Caller-receiver models for allogrooming, allofeeding, and kinship
	- Social relations models for allogrooming, allofeeding and kinship
	- Compares vocal reciprocity with allogrooming reciprocity
	- PRODUCTS: csvs and PDFs in *results* folder, R workspace (on Figshare, will load all relevant data without having to run the models) 

3. ~~03_get_recording_timestamps_XX.R~~

	- **NB**: This script ONLY WORKS on the computer that wrote the original WAV files! **DO NOT try to run.**
	- INPUTS: vocal_data_2024-pairs_XXXX-XX-XX.RDS, selection_tables_05-04-25.RDS
	- Gets timestamps for all WAV files from 2024 pairs that contain at least one usable call.
	- PRODUCT: 2024_recording_timestamps_2025-12-08.RDS

4. 04_antiphonal_test_XX.R

	- INPUTS: 2024_recording_timestamps_2025-12-08.RDS, trial_times.csv
	- Within each session, gets lag time between alternating calls made by different callers
	- Finds probability of a) overall antiphonal calling, b) each bat getting a response to a call, c) each bat giving a response to a call.
	- Permutation test: for each of 84 simulated sessions, randomly selects two bats from different real recording sessions and uses their observed call timing in those sessions to simulate two bats "calling" to each other. 
	- PRODUCTS: jpgs in *results* folder (call_intervals.jpg, getgive_probability.jpg)
	
	
Folders:
1. not_batcalls
    - Manually-selected spectrograms that are not bat calls.

2. results
    - All figures generated by this code that were published in the paper
    - CSVs of all model results
